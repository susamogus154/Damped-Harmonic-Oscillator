# Damped-Harmonic-Oscillator
A PINN predicting a damped harmonic oscillator's motion at different moments in time, using a physics loss function forcing the model to obey the damped harmonic oscillator ODE, Fourier feature encoding to reduce spectral bias, and a weighted loss function to focus on data points that have more information.

### How to run
Download the project folder, open the notebook, and run top to bottom. 
Data files go in /data/.
